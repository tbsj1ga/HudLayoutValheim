# Media for the README

- `icon-128.png` — the icon for the "More mods by j1gA" sections of the other mods
  (`thunderstore/icon.png` scaled down)
- `editor.webp` — animation: the F7 editor, a bar dragged and resized
- `styles.webp` — animation: a bar's style, numbers, cells and colour changed in the editor
- `bars.png` — numbers (75/100, %, current) and colours on a bar
- `elements.png` — the editor's list of elements, other mods' included

Animations: WebP, 4-8 s, 640-1280 px wide, under 4 MB. Cut from a 29 s recording
(3432×1318) with ffmpeg: cropped to the bar and the editor window, 1280 px, 12 fps, sped
up 1.6× / 2×.
