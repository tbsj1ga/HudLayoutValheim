# HudLayout

[English](README.md) · **Русский**

Мод для Valheim: перемещение, размер и вид HUD игрока — полос здоровья, выносливости,
эйтра и адреналина и значков еды. Редактор прямо в игре, выбор стиля для каждого элемента,
готовые пресеты и свои пресеты. Только клиент: другим игрокам и серверу ничего не нужно.

**Состояние: 0.9.1, все функции реализованы, ждёт проверки в игре.** Сборка сверена со
сборками текущей версии игры (`check-refs.ps1`); поведение в игре ещё не проверялось.
История: [CHANGELOG-RU.md](CHANGELOG-RU.md), план: [ROADMAP-RU.md](ROADMAP-RU.md).

## Что умеет

| Элемент      | Расположение                                                         | Внешний вид                                                          |
|--------------|----------------------------------------------------------------------|----------------------------------------------------------------------|
| Здоровье     | положение, размер, длина, толщина, фиксированная длина, горизонтально / вертикально, точка роста | стиль, видимость, непрозрачность, число (нет / 75 / 75/100 / 75%), размер числа, цвет полосы, значок сердца |
| Выносливость | то же                                                                | то же; *Всегда* — не исчезает                                        |
| Эйтр         | то же                                                                | то же                                                                |
| Адреналин    | то же                                                                | то же                                                                |
| Еда          | положение, размер, столбцом / строкой                                | стиль, видимость, непрозрачность, таймеры вкл/выкл, размер таймеров, символ еды |

- **Стили элемента** — готовый вид, выбирается для каждого элемента отдельно: у полос
  *Как в игре, Минимум, Числа, Проценты, Прозрачный, Контраст*; у еды *Как в игре, Без
  таймеров, Крупные таймеры, Прозрачный*. Выбор стиля заполняет настройки; ручное изменение
  любой из них делает стиль *Своим*.
- **Пресеты** описывают весь HUD: все пять элементов, расположение и вид. Встроенные:
  *Как в игре, По центру, По центру минимум, Слева внизу, Минимум, Числа*. Пресет можно
  применить целиком, только расположение (положение и размеры) или только внешний вид.
- **Свои пресеты**: сохранить текущий HUD под именем, удалить, скопировать в буфер одной
  строкой и импортировать пресет друга. Это текстовые файлы в
  `BepInEx/config/j1ga.hudlayout.presets/`, по одному на пресет, их можно править руками.

## Режим редактирования

Нажмите **F7** в игре (`00 General / EditModeKey`). Персонаж останавливается, появляется
курсор, у каждого элемента — рамка, и открывается окно с настройками выбранного элемента и
пресетами.

- **Перетаскивание** элемента — сдвиг; **жёлтый уголок** — размер.
- **Синяя ручка** на середине стороны полосы — длина или толщина.
- **Колесо** над элементом — размер; **Ctrl+колесо** — длина полосы; **Shift+колесо** — толщина.
- **ПКМ** — вернуть на место игры; **Shift+ПКМ** — сбросить всё его расположение.
- **Стрелки** двигают выбранный элемент (Shift ×10); **Tab** — следующий элемент.
- Положение привязывается к сетке (`GridStep`) и к середине экрана; с **Ctrl** при
  перетаскивании — свободно.
- **Esc** или **F7** закрывают редактор. Конфиг записывается один раз, при закрытии.

Скрытые элементы в редакторе видны полупрозрачными, чтобы их можно было найти.

## Консоль

`hudlayout edit | presets | apply <имя> [all|layout|style] | save <имя> | delete <имя> | export [имя] | import | reset | dump`

`dump` пишет иерархию HUD в лог BepInEx — пригодится при сообщении об ошибке.

## Конфиг

`BepInEx/config/j1ga.hudlayout.cfg`: по секции на элемент (`01 Health` … `05 Food`) и
`00 General`. Всё, что меняет редактор, пишется туда же, поэтому ConfigurationManager (F1)
показывает и меняет те же значения на лету. `PositionX/Y = -1` — «там, где ставит игра».
Положение — доля экрана: `0,0` — левый нижний угол, `1,1` — правый верхний.

`Enabled = false` возвращает HUD точно к виду игры, настройки сохраняются.

## Совместимость

- Моды, которые **заменяют** HUD (Auga и подобные), — несовместимы, нужен один из двух.
- Моды, которые ищут объекты HUD **по пути** (`hudroot/healthpanel/...`), их не найдут:
  полосы теперь на уровень глубже, в обёртках `HudLayout_<Элемент>`. Моды, которые держат
  объекты по ссылке (обычный случай), это не затрагивает.
- В режиме строительства и у руля игра поднимает полосы выносливости, эйтра и адреналина;
  перемещённые полосы поднимаются на столько же (`FollowBuildShift`).

## Сборка

`powershell -ExecutionPolicy Bypass -File .\build.ps1` — собирает `build\HudLayout.dll`
компилятором `csc.exe` из .NET Framework против установленной игры и профиля r2modman (пути
в начале скрипта) и сверяет все ссылки и цели Harmony с текущей версией игры
(`check-refs.ps1`). `-Install` копирует в plugins профиля, `-Package` собирает zip для
Thunderstore (нужен `thunderstore/icon.png`, 256×256).
