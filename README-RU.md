# HudLayout

[English](README.md) · **Русский**

Мод для Valheim (в планах): перемещение, размер и вид HUD игрока — полос здоровья,
стамины, эйтра и адреналина и значков еды. Сначала фиксированная раскладка из конфига,
затем режим редактирования в игре: перетаскивать элементы мышью, менять размер за уголки
и переключать вид отображения. Только клиент: другим игрокам и серверу ничего не нужно.

**Состояние: проектирование, кода пока нет.** История версий будет в `CHANGELOG-RU.md`.
