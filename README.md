# HudLayout

**English** · [Русский](README-RU.md)

A Valheim mod (planned): move, resize and restyle the player's HUD — health, stamina,
eitr and adrenaline bars and the food icons. First a fixed layout from the config, then an
in-game edit mode: drag the elements with the mouse, resize them by their corners and
switch how they are displayed. Client-side only; other players and the server need
nothing.

**Status: design stage, no code yet.** History will be in `CHANGELOG.md`.
